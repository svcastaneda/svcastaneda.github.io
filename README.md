GitHub Pages personal website made using jekyll, yml, HTML, CSS, and javascript

## Setup
1. Clone the repo
2. `cd` into the new directory that was created (`svcastaneda.github.io` by default)
3. Install the gems with `bundle install`

## How to run the app locally
1. In your terminal, run `bundle exec jekyll serve`
2. Open a new tab or window in your web browser
3. Navigate to [http://127.0.0.1:4000/](http://127.0.0.1:4000/)
